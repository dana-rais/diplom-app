# 01. Project Proposal

## 1. Project Overview
* **Project Title:** Development of a Mobile Application for Teaching Digital Literacy to Older Adults with Interactive Training Simulations.
* **Developer:** Nurdana Moldabay (Group SE-2406) — Individual project.
* **Supervisor:** Arstan Makatov

## 2. Problem Statement
Elderly people often face significant difficulties when mastering modern smartphones and mobile applications due to:
1. High fear of making a mistake (e.g., accidentally transferring money or deleting important data).
2. Small UI elements, complex terminology, and non-intuitive navigation logic.
3. The lack of a safe practice environment where errors carry no real financial or psychological consequences.

## 3. Target Users
* **Primary Users:** Elderly individuals (50+ years old) who own a smartphone but use only basic functions (like calls) due to lack of confidence or skills.
* **Secondary Users:** Relatives and social workers who assist elderly people in learning basic mobile skills.

## 4. Aim and Objectives
* **Aim:** To develop an accessible cross-platform mobile application featuring safe interactive simulators for step-by-step acquisition and reinforcement of basic digital literacy skills among elderly users.
* **Objectives:**
  1. Research UX/UI needs of elderly users (large fonts, high contrast, simple terminology, step-by-step feedback).
  2. Develop interactive simulators of real-world interfaces (e.g., sending messages in a messenger, searching for information, basic simulator for secure banking/gov services).
  3. Implement step-by-step hints, audio/text guidance, and gentle error handling.
  4. Build a scalable Flutter/Dart application architecture focused on training scenarios.
  5. Conduct usability testing with representatives of the target audience.

## 5. Project Scope & Expected Outcomes
* **Expected Outcomes:**
  * A fully designed and tested cross-platform mobile application (Android / iOS / Web demo).
  * A set of 3–5 key training simulator modules (e.g., "Gestures & Taps", "Messengers & Photos", "Security & Passwords", "Basic Simulator").
* **Project Scope:**
  * **Included:** Safe simulations of user actions, built-in local user progress tracking, large UI components support, and descriptive guidelines.
  * **Excluded:** Real integration with live banking APIs or official government services (all financial and personal operations are restricted to a secure test simulator).
