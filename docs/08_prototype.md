# 08. UX/UI Prototype and Figma Link

## 1. Overview
The user interface (UI) and user experience (UX) of the proposed application are designed specifically to meet the cognitive and physical needs of elderly users (50+ years old). The design minimizes cognitive load, ensures high visual accessibility, and provides safe, stress-free interaction patterns.

## 2. Core Design Principles for Elderly Users
* **Large Touch Targets:** Interactive buttons and elements are designed with generous padding and sizing (minimum 44x44 dp) to accommodate reduced motor precision.
* **High Legibility & Contrast:** Features adjustable font scaling (from 100% to 150%) and distinct color themes (Light mode and High Contrast mode).
* **Step-by-Step Breakdown:** Complex operations are divided into isolated, single-action screens to prevent user disorientation and fear of mistakes.
* **Multimodal Feedback:** Combines visual text guidance with optional audio narration ("Озвучить") to support users with age-related visual impairments.

## 3. Key Screen Layouts
1. **Home / Lessons Screen:** Displays structured training categories (Basic Gestures, Calls & SMS, Gov/Bank, Cybersecurity) with clear status badges.
2. **Progress Screen:** Visually tracks overall course completion (e.g., 9 out of 21 lessons completed) alongside sectional progress bars.
3. **Settings Screen:** Provides instant controls for language switching (Kazakh / Russian), font scaling, and theme selection.
4. **Interactive Simulation Screens:** Safe, isolated mockups of real-world interfaces (e.g., incoming scam calls, fraudulent SMS alerts) equipped with non-punitive hints and guidance buttons.
