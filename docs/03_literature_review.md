# 03. Literature Review

## 1. Overview
This critical review analyzes academic and technical sources related to accessibility, user interface design for elderly users, and gamified digital literacy simulators. The review includes 12 meaningfully used sources, with at least 8 scientific publications, primarily focusing on works published within the last five years.

## 2. Structured Source Analysis

| № | Author(s) & Year | Title / Source | Key Findings / Approaches | Limitations / Application in Project |
|---|---|---|---|---|
| 1 | World Wide Web Consortium (W3C), 2023 | Web Content Accessibility Guidelines (WCAG) 2.2 | Establishes standard accessibility requirements including contrast ratio (at least 4.5:1), touch target sizing (minimum 44x44 dp), and text scalability. | Applied directly to define UI design constraints and baseline accessibility metrics. |
| 2 | Kurniawan, S., & Zaphiris, P., 2019 | Research-Derived Web Design Guidelines for Older People | Highlights the necessity of clear visual feedback, minimal cognitive load, and avoiding complex multi-touch gestures. | Used to formulate guidelines for simulator interaction patterns (focusing on single taps). |
| 3 | Wildenbos, G. A., Peute, L., & Jaspers, M., 2018 | Aging barriers influencing mobile health usability for older adults: A literature based framework (MOLD-US) | Systematizes cognitive, physical, and perceptual barriers faced by older adults when interacting with mobile interfaces. | Serves as a foundational theoretical framework for designing simplified touch interactions and clear feedback. |
| 4 | Blažič, B. J., & Blažič, A. J., 2020 | Overcoming the digital divide with a modern approach to learning digital skills for the elderly adults | Demonstrates the effectiveness of structured digital skill training adapted to older populations. | Validates the pedagogical approach of teaching digital literacy through active skill-building modules. |
| 5 | Juera, L. C., 2024 | Digitalizing skills development using simulation-based mobile (SiM) learning application | Evaluates how interactive mobile simulation applications accelerate practical skill acquisition compared to traditional methods. | Informs the technical design of step-by-step interactive simulators within the application. |
| 6 | Zhou, C., Yuan, F., Huang, T., & Zhang, Y., 2022 | The impact of interface design element features on task performance in older adults: evidence from eye-tracking and EEG signals | Analyzes how UI element features affect search performance and visual attention in elderly users. | Applied to optimize UI layout, icon placement, and visual contrast to reduce cognitive load. |
| 7 | Gao, Q., & Sun, Q., 2015 | Examining the usability of touch screen gestures for older and younger adults | Evaluates older adults' performance across various touchscreen gestures (e.g., tap vs. drag/swipe). | Restricts initial training modules to single-tap gestures to minimize physical interaction errors. |
| 8 | ISO Standardization, 2019 | ISO 9241-210: Human-centred design for interactive systems | Provides standard principles and processes for human-centered design throughout the software lifecycle. | Serves as the core methodological framework for user research, prototyping, and usability evaluations. |
| 9 | Choudrie, J., Junior, C. O., McKenna, B., & Richter, S., 2018 | Understanding and conceptualising the adoption, use and diffusion of mobile banking in older adults | Identifies primary barriers to adopting mobile banking services among seniors, emphasizing security fears and complexity. | Justifies the creation of a risk-free, simulated banking/financial interface for safe practice. |
| 10 | Mascetti, S., Ducci, M., Cantù, N., & Pecis, P., 2021 | Developing accessible mobile applications with cross-platform development frameworks | Compares accessibility API support and UI tree generation across cross-platform frameworks. | Validates the feasibility of implementing accessible components in Flutter. |
| 11 | Bimba, A. T., Idris, N., Al-Hunaiyyan, A., et al., 2017 | Adaptive feedback in computer-based learning environments: a review | Reviews mechanisms for adapting feedback to learner performance in interactive educational systems. | Guides the implementation of gentle, adaptive hint sequences when a user makes repeated errors in a simulator. |
| 12 | Perim, C., Sousa, C., & Damásio, M. J., 2024 | Game-based learning for fostering digital literacy in older adults: an intergenerational approach | Explores game-based learning strategies to improve engagement and retention during digital skill acquisition. | Supports the inclusion of lightweight gamification elements (badges, progress indicators) without adding pressure. |
