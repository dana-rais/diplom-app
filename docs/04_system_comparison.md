# 04. Existing System Comparison

## 4.1. Overview
 
This section compares five existing systems that help older adults use digital technology against one consistent set of nine criteria. The aim is to show which needs are already covered, which are not, and why a dedicated interactive simulator is justified.
 
**Method.** The comparison is a documentary review of official project pages, government and library descriptions, and independent reviews, checked on 23 October 2026. Every rating in the matrix is linked to a source in Section 4.5. Where no source documents a feature, the cell is marked "not documented" rather than assumed. The proposed application is not yet built, so its column describes **design goals**, not achieved results.
 
**Legend:** ✅ supported · ⚠️ partly supported · ❌ not supported · ❔ not documented in the sources found · 🎯 planned design goal

## 4.6. Analysis of Findings
 
**What existing systems do well.** Four of five systems provide structured, self-paced or instructor-led content for older or beginner learners (S2–S5), and several cover online safety (S2–S5). BIG Launcher (S1) addresses interface readability for seniors and people with low vision.
 
**Gaps.**
 
1. **Launchers do not teach.** BIG Launcher simplifies the interface, but the sources describe no lessons, exercises, or feedback. It changes the screen the user sees rather than building skills for the standard phone.
2. **Learning portals are mostly web-based and content-led.** S2–S4 deliver lessons through websites with text, video, and exercises. The sources found describe interactive activities (strongest for S2), but none documents a mobile application that simulates smartphone gestures and everyday tasks such as calls and messages.
3. **Live classes depend on instructors.** Senior Planet (S5) provides valuable personal support, but live classes need scheduled sessions and staff. This matches the limitation seen in workshop-based studies in the Literature Review (Quialheiro et al., 2023; Siriwattanarat et al., 2025).
4. **Safe practice is limited.** Be Connected's pretend online bank shows the value of a practice environment, but it covers banking tasks, not general phone use.
5. **Designed-for-older-adults design varies.** Learn My Way and GCFLearnFree target beginners or the general public rather than older adults specifically.
## 4.7. Justification of the Proposed Solution
 
Existing systems cover parts of the problem: interface simplification (S1), online lessons (S2–S4), and instructor-led support (S5). Based on the sources reviewed, none combines all of the following in one mobile application: simulated everyday phone tasks, scam-recognition practice, immediate non-punitive feedback, and independent repetition.
 
This supports the Literature Review, which found that interactive practice and accessible design are usually studied separately and that most training depends on human support (Section 3.5). The proposed simulator therefore aims to combine a senior-friendly interface (Gomez-Hernandez et al., 2023), scenario-based tasks connected to daily life (Schirmer et al., 2022), and repeatable practice that does not require an instructor.
 
**Caution.** The advantage of the proposed application is a hypothesis, not an established result. It must be tested through usability testing and learning assessments with older adults. The comparison also does not claim that existing systems are ineffective: several have large user bases and positive reported outcomes. It claims only that the specific combination of features above was not found in the sources reviewed.
